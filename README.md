# DeskAI

DeskAI is a lightweight Windows desktop AI assistant built with Python and PySide6.

The goal is to provide quick access to an AI assistant directly from the Windows desktop without opening a browser.

## Planned v0.1.0 Features

- Desktop AI chat window
- Multi-turn conversations
- Non-blocking AI requests
- System tray support
- Global hotkey
- Windows startup support
- Secure API key configuration
- Basic error handling

## Tech Stack

- Python
- PySide6
- Large Language Model API
- Git / GitHub
